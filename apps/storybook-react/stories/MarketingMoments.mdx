# Marketing moment

**Category:** Other

**Components used:** Box, Button, Icon, Text

**Last updated:** Oct 13, 2026

A marketing moment is a full-screen decision. It introduces one product opportunity, or confirms one step in a setup flow, and asks the user to continue or leave.

<Canvas of={MarketingMomentStories.Default} />

## What this pattern does

It gives the user a single, interruptive choice: take the offered action now, or dismiss the screen and return to what they were doing. The screen owns the viewport so the choice is not competing with the rest of the product.

## When to use this pattern

Use a marketing moment when the user has to make one decision before they can continue, and that decision is the point of the screen.

- Announcing a product the user has not started, such as MetaMask Card, Perps, or an invitation.
- Confirming a step that already happened and pointing to the one action that should happen next.
- The user can safely postpone the action. Dismissal is a complete outcome, not an error.

## When not to use this pattern

- If the message should stay visible while the user keeps using the current screen, use [BannerAlert](?path=/docs/react-components-banneralert--docs) instead.
- If the user must confirm or cancel a destructive action on top of the current screen, use [Modal](?path=/docs/react-components-modal--docs) instead.
- If the only job is to confirm that something finished and then get out of the way, use [Toast](?path=/docs/react-components-toast--docs) instead.
- If the screen collects more than one decision, use the form or flow those fields belong to. A marketing moment is not a wizard step.

## Composition

Every moment has the same frame: a phone-width screen, one content stack, and two actions pinned to the bottom. There are no navigation buttons. No back button, close icon, or header action. `Not now` is how the user leaves.

**Required**

- A title, rendered as the page heading. The title always uses `TextVariant.DisplayMd`. Do not drop the size to fit a longer title. If the title wraps too far, shorten the words.
- One or two sentences of description, in body text. A second paragraph is only for a fact that does not belong in the first sentence, such as when a card will arrive.
- Artwork. In these examples the artwork is an icon in a muted frame. Swap in product art without changing the stack.
- One primary button. Its label names the action (`Set up card`, `Finish setup`, `Accept invite`).
- One tertiary button directly under the primary button, labeled `Not now`. It closes the moment immediately and returns the user to the previous screen.

**Layout**

There is one layout. The title and description sit at the top. The asset is centered in the space between the copy and the actions. The actions stay at the bottom. Title size, description size, artwork frame, and buttons do not change from one moment to the next.

The content does not scroll. If the description needs a third paragraph, shorten the copy before adding scroll.

## State coverage

The Storybook examples show the resting screen. Product implementations also need the transitions below.

- **Resting.** The user sees the title, description, artwork, and actions. Activating the primary button or `Not now` leaves this state.
- **Continuing.** The primary button can show its loading state while the next step opens. The rest of the screen stays put. Success leaves this screen. Failure stays here and explains what went wrong in the description, or in a banner on the next screen, not in a second marketing moment.
- **Dismissed.** The moment is gone and the user is back on the screen they came from. Do not show the same moment again in the same session.
- **Completed.** The moment is gone because the user took the action. Later entry points use the product's normal empty, in-progress, or done states. Do not show the invitation again.

This pattern has no empty state. If there is no moment to show, render the underlying screen.

This pattern has no disabled state. If the user cannot take the action yet, do not show the moment.

## Accessibility

This screen replaces the current view. It is not a dialog, so do not trap focus and do not move focus into a container that the user cannot leave.

- The title is the only page heading. Move focus to that heading when the screen opens so the name and purpose are announced together.
- Tab order follows the visual order: heading, description, primary button, then `Not now`.
- Both actions are buttons. Activate them with Enter or Space.
- The artwork is decorative. Do not give it a name that repeats the title.
- When the user dismisses the screen, return focus to the control that opened it.
- When the user continues, move focus to the heading of the next screen.

## Anti-patterns

- Adding any navigation button, including back, close, or a header action. `Not now` already leaves the screen.
- Omitting `Not now`, or renaming it. Every moment can be left immediately, and the label stays the same so the way out is recognizable.
- Changing the title size between moments. A long title gets shorter copy, not a smaller style.
- Two primary buttons. The screen has one recommended action. The other choice is tertiary.
- Title case on the heading or the buttons. Write `Set up card`, not `Set Up Card`. Product names such as MetaMask Card and Perps stay capitalized.
- Moving the asset above the title, or pinning it directly under the copy so the frame changes from moment to moment. The asset stays centered between the copy and the actions.
- Reusing the moment as an error or a loading screen. Those states belong to the flow the primary button opens.

## Related patterns

- **Banner alert.** Often confused with a marketing moment because both announce something. A banner stays on the current screen. A marketing moment is the screen.
- **Modal.** Often confused with a marketing moment because both ask for a decision. A modal covers the current task and returns to it. A marketing moment is a destination.
- **Toast.** Used after a marketing moment, not instead of one, when a later step only needs a short confirmation.
