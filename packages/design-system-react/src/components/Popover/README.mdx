# Popover

`Popover` is a floating layer that positions itself against a reference element. Use it for tooltips, menus, and other contextual content that needs to anchor to a trigger. Wire `referenceElement`, `isOpen`, and one of `onPressEscKey` / `onClickOutside` to control visibility from the trigger.

`Popover` is built on native web platform APIs and has no positioning-library dependency:

- **[Popover API](https://developer.mozilla.org/docs/Web/API/Popover_API)** — the root renders with `popover="manual"` and is shown in the browser's top layer, so ancestors with `overflow: hidden` or their own stacking context cannot clip or cover it. Visibility stays controlled by `isOpen`; native light dismiss is not used.
- **[CSS anchor positioning](https://developer.mozilla.org/docs/Web/CSS/CSS_anchor_positioning)** — used when the browser supports it (Chrome 128+, Firefox 147+, Safari 26+) and the configuration can be expressed in CSS: a fixed `position` without `hasArrow` or `preventOverflow`. `Popover` sets a generated `anchor-name` on `referenceElement` while open and restores the previous value on close.
- **Positioning fallback** — everything else (older browsers, `PopoverPosition.Auto`, `hasArrow`, `preventOverflow`) uses a small built-in positioning utility that measures the reference element and updates on scroll and resize.

```tsx
import { Popover, PopoverPosition } from '@metamask/design-system-react';

<Popover
  isOpen={isOpen}
  referenceElement={referenceElement}
  position={PopoverPosition.Bottom}
  onPressEscKey={() => setIsOpen(false)}
>
  Popover contents
</Popover>;
```

### `isPortal`

Renders the popover into `document.body` via `createPortal` instead of inline. Rarely needed: because the popover is shown in the top layer, it is not clipped by ancestors with `overflow: hidden` even when rendered inline. Keep it for DOM-order reasons (for example, CSS selectors or event delegation that expect the popover under `body`). Avoid it for popovers opened from inside a modal `<dialog>`: content outside the dialog is inert while it is open, so render those popovers inline.

### `referenceHidden`

Hides the popover (`visibility: hidden; pointer-events: none`) when the reference element is scrolled out of view, including out of a scrolling ancestor. Driven by the `data-popper-reference-hidden` attribute on the popover root, which is measured by the positioning fallback or, with CSS anchor positioning, by an `IntersectionObserver` on the reference element.
