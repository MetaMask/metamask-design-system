# HeaderStandard

`HeaderStandard` is a centered page or modal header with optional back and close actions. It composes [HeaderBase](../HeaderBase/README.mdx) and resolves shortcut props to [ButtonIcon](../ButtonIcon/README.mdx) accessories.

```tsx
import { HeaderStandard } from '@metamask/design-system-react';

<HeaderStandard title="Page title" onBack={handleBack} onClose={handleClose} />;
```

## Props

### `title`

Primary label in the header center. Ignored when `children` is set.

When `title` is a string, it uses `TextVariant.BodyMd` and bold weight by default; use `titleProps` to override. Nodes render as-is without `titleProps`.

### `startButtonIconProps` / `endButtonIconProps`

Optional `ButtonIcon` prop bags. `startButtonIconProps` wins over `onBack`. `endButtonIconProps` items render after the close button and reverse so the first item is rightmost. Explicit `startAccessory` / `endAccessory` from HeaderBase win over these helpers. Each React `ButtonIcon` requires `ariaLabel`.

## Content guidelines

- Sentence case for multi-word screen titles
- No trailing period on titles

```
✅ "Account settings"
❌ "Account Settings"
```
