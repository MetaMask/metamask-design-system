# HeaderSubpage

A left-aligned navigation header for secondary pages that need identity content such as an avatar, title, or description alongside navigation actions. Use HeaderSubpage for subpage headers; use HeaderBase or ModalHeader when the title should be centered.

```tsx
import {
  AvatarToken,
  AvatarTokenSize,
  HeaderSubpage,
  Icon,
  IconColor,
  IconName,
} from '@metamask/design-system-react';

<HeaderSubpage
  avatar={
    <AvatarToken
      src="https://cryptologos.cc/logos/ethereum-eth-logo.svg"
      size={AvatarTokenSize.Lg}
      name="Ethereum"
    />
  }
  title="Ethereum"
  description="ETH"
  titleEndAccessory={
    <Icon name={IconName.VerifiedFilled} color={IconColor.PrimaryDefault} />
  }
  onBack={() => {}}
/>;
```

### `onBack`

Callback when the back button is pressed. If provided, a back button is rendered as the start accessory. The button uses a default English `ariaLabel` of "Go back"; override via `backButtonProps.ariaLabel` for localization. Use `backButtonProps` to pass additional props to the back ButtonIcon. If `backButtonProps` is provided without `onBack`, a back button is still rendered.

If `closeButtonProps` is provided without `onClose`, a close button is still rendered.

### `endAccessory`

Optional content after the identity content. Use this escape hatch when you need complete control over the end slot. Use `endButtonIconProps` to render additional end ButtonIcons when `endAccessory` is not provided. Items are rendered in reverse order (first item appears rightmost). `endAccessory` takes priority over `endButtonIconProps` and close shortcuts.
