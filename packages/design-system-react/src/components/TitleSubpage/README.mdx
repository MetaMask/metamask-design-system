# TitleSubpage

TitleSubpage lays out a required identity block (leading `titleAvatar` beside a title stack), an optional subtitle, an optional amount row, optional bottom rows, and optional inline accessories per row. Prefer `AvatarToken` at `AvatarTokenSize.Lg` (40×40) for the standard token footprint; wrap in `BadgeWrapper` when a network badge should sit outside the token bounds.

```tsx
import {
  AvatarToken,
  AvatarTokenSize,
  TitleSubpage,
} from '@metamask/design-system-react';

<TitleSubpage
  titleAvatar={<AvatarToken name="ethereum" size={AvatarTokenSize.Lg} />}
  title="Send"
/>;
```

### `amount`

Optional primary amount line below the title and optional subtitle. The amount row renders when `amount` is truthy. When `amount` is a string, it uses `TextVariant.DisplayLg` (merged with `amountProps`) and renders as a `p` element: display typography without heading semantics, so the component keeps a single heading (the title). String slots render through `SensitiveText`, so `amountProps={{ isHidden: true }}` masks the amount with bullets, matching React Native.

## Accessibility

- A string `title` renders as an `h4` (`TextVariant.HeadingSm`), and the component renders no other heading: a string `amount` renders as a `p`, so heading order stays valid when the component is composed into a page. When the surrounding page needs a different title level, pass a `title` node and set the element with `asChild`:

```tsx
import { Text, TextVariant, TitleSubpage } from '@metamask/design-system-react';

<TitleSubpage
  titleAvatar={<AvatarToken name="ethereum" size={AvatarTokenSize.Lg} />}
  title={
    <Text variant={TextVariant.HeadingSm} asChild>
      <h2>USD Coin</h2>
    </Text>
  }
/>;
```

- String slots render through `SensitiveText`, so `titleProps`, `subtitleProps`, `amountProps`, or `bottomLabelProps` with `isHidden: true` mask the content with bullets.
- The `*EndAccessory` icons in the story examples (for example `IconName.Info`) are decorative and hidden from assistive tech. An accessory that carries meaning needs an accessible name (for example an `aria-label` on the icon or a text label).
