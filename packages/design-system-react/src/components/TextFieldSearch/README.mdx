# TextFieldSearch

TextFieldSearch is the component for search and filtering experiences. Use it when people need to search or filter. For a general-purpose text input, use `TextField`.

```tsx
import { TextFieldSearch } from '@metamask/design-system-react';

<TextFieldSearch
  inputAriaLabel="Search tokens"
  placeholder="Search"
  value={search}
  onChange={(event) => setSearch(event.target.value)}
  clearButtonOnClick={() => setSearch('')}
/>;
```

The component is controlled. Wire `value`, `onChange`, and `clearButtonOnClick` to your own state — the clear button always renders when `value` is truthy and `clearButtonOnClick` is required.

## Props

The clear button is rendered automatically after the input whenever `value` is truthy.

### `clearButtonOnClick`

Click handler invoked when the clear button is pressed. Use it to reset the controlled `value`.

### `clearButtonProps`

Additional props forwarded to the underlying `ButtonIcon`. Use `clearButtonProps.ariaLabel` to provide a localized label (defaults to `'Clear'`).

<Canvas of={TextFieldSearchStories.ClearButtonProps} />

### `size`

Inherited from `TextField`. Controls the height of the container.

<Canvas of={TextFieldSearchStories.Size} />

### `isDisabled`

Inherited from `TextField`. Disables the inner input and the clear button container.

<Canvas of={TextFieldSearchStories.IsDisabled} />

### `isError`

Inherited from `TextField`. Renders the error border treatment.

<Canvas of={TextFieldSearchStories.IsError} />

### `inputAriaLabel`

Required name for the inner search input. It renders no text. It takes precedence over `inputProps['aria-label']`.

A top-level `aria-label` is not an alternative: it names the `<search>` landmark, not the input.

<Canvas of={TextFieldSearchStories.InputAriaLabel} />

### Other props

All other `TextField` props (`isReadOnly`, `placeholder`, `inputProps`, `inputRef`, `startAccessory`, `endAccessory`, etc.) are supported. The `type` prop is fixed to `'search'` and is not configurable.
