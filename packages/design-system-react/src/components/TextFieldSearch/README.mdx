# TextFieldSearch

TextFieldSearch is a controlled search input built on top of `TextField`. It renders a `<search>` landmark, a leading search icon, a native search input, and a trailing clear button when the field has a value. This field does not show a separate visible label, so `inputAriaLabel` is required and names both the landmark and the input. Placeholder text is only a visible hint. Use it for filtering or search experiences; for a general-purpose text input, use `TextField`. Do not wrap it in another `<search>` element.

```tsx
import { TextFieldSearch } from '@metamask/design-system-react';

<TextFieldSearch
  inputAriaLabel="Search tokens"
  placeholder="Search tokens"
  value=""
/>;
```

The component is controlled. Wire `value`, `onChange`, and `clearButtonOnClick` to your own state — the clear button always renders when `value` is truthy and `clearButtonOnClick` is required.

## Props

The clear button is rendered automatically after the input whenever `value` is truthy.

### `inputAriaLabel`

Required accessible name for the search input. Set as `aria-label` on the input and on the `<search>` landmark, so more than one search field on a page can be told apart.

This component never renders a visible label. Do not use `placeholder` as the name. `inputAriaLabel` replaces an `aria-label` passed through `inputProps`.

<Canvas of={TextFieldSearchStories.InputAriaLabel} />

### `clearButtonOnClick`

Click handler invoked when the clear button is pressed. Use it to reset the controlled `value`.

### `clearButtonProps`

Additional props forwarded to the underlying `ButtonIcon`. Use `clearButtonProps.ariaLabel` to provide a localized label (defaults to `'Clear'`).

<Canvas of={TextFieldSearchStories.ClearButtonProps} />

### `size`

Inherited from `TextField`. Controls the height of the container.

<Canvas of={TextFieldSearchStories.Size} />

### `isDisabled`

Inherited from `TextField`. Disables the inner input and the clear button container.

<Canvas of={TextFieldSearchStories.IsDisabled} />

### `isError`

Inherited from `TextField`. Renders the error border treatment.

<Canvas of={TextFieldSearchStories.IsError} />

### Other props

All other `TextField` props (`isReadOnly`, `placeholder`, `inputProps`, `inputRef`, `startAccessory`, `endAccessory`, etc.) are supported. The `type` prop is fixed to `'search'` and is not configurable.

`className` is applied to the `<search>` landmark and to the field. Width and flex utilities size the landmark, and the field fills it. Margin and padding utilities are applied to both, so keep spacing on a parent element. `ref` still points at the field container, not the landmark.
