# ModalOverlay

`ModalOverlay` is a decorative layer that covers the viewport behind a modal.

- **Inside `Modal`** (the recommended usage), the page is already dimmed by the native `<dialog>` `::backdrop`, so `ModalOverlay` renders a transparent `absolute inset-0` layer that counts as part of the dismissible area (clicking it calls `onClose` when `isClosedOnOutsideClick` is `true`). It is optional and kept for backwards compatibility. Add a color with `className` (for example `bg-black/20`) if you want an extra tint on top of the backdrop.
- **Standalone** (outside `Modal`), it keeps its original behavior: a fixed, full-viewport element with the default overlay color and fade-in animation.

```tsx
import { ModalOverlay } from '@metamask/design-system-react';

<ModalOverlay onClick={handleClose} />;
```

## Props

### `onClick`

Optional click handler invoked when the overlay is clicked. Useful for closing the modal when the user clicks outside its content. Not necessary when used inside `Modal` with `isClosedOnOutsideClick` enabled.

### `className`

Use the `className` prop to add custom CSS classes to the component. These classes will be merged with the component's default classes using `twMerge`, allowing you to:

- Add new styles that don't exist in the default component
- Override the component's default styles when needed
