# HeaderSearch

HeaderSearch is a header row that combines `TextFieldSearch` with either a back icon (`Screen` variant) or a tertiary **Cancel** action (`Inline` variant). Props are a discriminated union on `variant`.

```tsx
import {
  HeaderSearch,
  HeaderSearchVariant,
} from '@metamask/design-system-react';

<HeaderSearch
  variant={HeaderSearchVariant.Screen}
  onClickBackButton={handleBack}
  textFieldSearchProps={{
    inputAriaLabel: 'Search',
    value: searchText,
    onChange: (event) => setSearchText(event.target.value),
    clearButtonOnClick: () => setSearchText(''),
    placeholder: 'Search',
  }}
/>;
```

## When to use

- Use **`Screen`** when the search field sits on its own route or full-width header and users expect a **back** control.
- Use **`Inline`** when search is toggled **inside** an existing screen and users dismiss it with **Cancel**.
- Prefer this component over composing `Box`, `ButtonIcon`, and `TextFieldSearch` by hand when you want consistent spacing and height.

## Props

The component extends root layout props from `Box` (except `children`). Required handlers depend on `variant`.

### `variant`

Selects layout and primary chrome: back button versus cancel button.

Available values:

- `HeaderSearchVariant.Screen` — `ButtonIcon` with `ArrowLeft` on the start edge.
- `HeaderSearchVariant.Inline` — `Button` (tertiary) labeled **Cancel** on the end edge.

## Migration from Extension

| Old (Extension local) | New (MMDS React) | Notes |
| --------------------- | ---------------- | ----- |
| `onClickBackButton` / `onClickCancelButton` | Same | Keep web `onClick*` naming |
| Inline cancel = `ButtonIcon` Close | Tertiary **Cancel** `Button` | Matches React Native MMDS |
| `textFieldSearchProps.onChangeText` adapter | Native `onChange` / `clearButtonOnClick` | Use React `TextFieldSearch` props directly |
| `HeaderSearchVariant` enum | Shared const object | Import from `@metamask/design-system-react` |

## Content guidelines

- `textFieldSearchProps.placeholder`: sentence case with imperative starters such as `"Search"`
- Button labels: sentence case, no period (`Cancel`)
