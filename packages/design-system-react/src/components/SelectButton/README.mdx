# SelectButton

SelectButton is a compact row for opening a picker or menu: it shows a **`placeholder`** or selected **`value`**, optional leading content, and a trailing chevron (by default **down**) unless you hide it or swap in custom trailing content. Use it on its own for filters and dropdown-style actions.

```tsx
import { SelectButton } from '@metamask/design-system-react';

<SelectButton placeholder="Select an option" onClick={() => {}} />;
```

## Props

The props contract is **`SelectButtonProps`** from **`@metamask/design-system-react`**. It includes all **`ButtonBase`** props except **`children`**, **`endIconName`**, **`endIconProps`**, **`disabled`**, and the button form **`value`** (use **`isDisabled`**; **`value`** is the selected label, derived with **`placeholder`**).

### `placeholder`

Label text when **`value`** is **`undefined`** or **`null`**. An empty string **`""`** still counts as a selected label, not a placeholder.

### `variant`

Controls row styling and default label colors.

Available values:

- `SelectButtonVariant.Primary` — muted filled row (default). Matches `Button` secondary styling, including hover and active backgrounds.
- `SelectButtonVariant.Secondary` — transparent row (`border-0`); hover, active, and loading use the pressed background.
- `SelectButtonVariant.Tertiary` — same container as secondary, with alternative label and trailing-arrow colors when using defaults.

### `endArrowDirection`

Maps to the trailing **`Icon`**: **`ArrowUp`**, **`ArrowDown`**, **`ArrowLeft`**, or **`ArrowRight`**. When omitted and **`endAccessory`** is not used, the chevron defaults to **down**. When **`endAccessory`** is set and **`endArrowDirection`** is omitted, the accessory shows instead of the arrow. If both are set, the arrow wins and **`endAccessory`** is ignored.

Available values:

- `SelectButtonEndArrow.Up`
- `SelectButtonEndArrow.Down`
- `SelectButtonEndArrow.Left`
- `SelectButtonEndArrow.Right`

### `className`

Use the `className` prop to add Tailwind CSS classes to the root row. These classes will be merged with the component's default classes using `twMerge`, allowing you to:

- Add new styles that don't exist in the default component
- Override the component's default styles when needed

### `size`

Controls the height of the button. Use `SelectButtonSize` values to keep the type aligned with the component API.

Available values:

- `SelectButtonSize.Sm` — 32px height.
- `SelectButtonSize.Md` — 40px height.
- `SelectButtonSize.Lg` — 48px height.
