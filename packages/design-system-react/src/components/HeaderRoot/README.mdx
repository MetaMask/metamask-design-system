# HeaderRoot

`HeaderRoot` is a header with a left section and an end section (`endAccessory` or `endButtonIconProps`). Use it on **top-level entry screens** that do **not** need back navigation (for example home or root tabs). Use **HeaderBase** when users need **back navigation**.

```tsx
import { HeaderRoot, IconName } from '@metamask/design-system-react';

<HeaderRoot
  title="Screen Title"
  endButtonIconProps={[
    {
      iconName: IconName.Close,
      ariaLabel: 'Close',
      onClick: handleClose,
    },
  ]}
/>;
```
