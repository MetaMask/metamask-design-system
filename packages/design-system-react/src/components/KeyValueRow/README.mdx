# KeyValueRow

KeyValueRow shows a key (label) on the left and a value on the right with optional accessories, for summaries, forms, and lists.

```tsx
import { KeyValueRow } from '@metamask/design-system-react';

<KeyValueRow keyLabel="Network" value="Ethereum Mainnet" />;
```

<Canvas of={KeyValueRowStories.Default} />

## Props

### `keyLabel`

The key content, as a string or custom `ReactNode`. Named `keyLabel` to avoid React's reserved `key` prop. When a string, rendered with BodyMd Medium TextAlternative and ellipsis (overridable via `keyTextProps`).

  KeyValueRowVariant,
} from '@metamask/design-system-react';

/>;

### `keyEndButtonIconProps`

When this object includes an `iconName`, a `ButtonIcon` is rendered as the key’s end accessory (and takes precedence over `keyEndAccessory`). Pass `ariaLabel` and typically `onClick`. Defaults: size Sm, icon color IconAlternative, `ariaLabel` `"More information"` when omitted.

### `className`

Use the `className` prop to add Tailwind CSS classes to the component. These classes are merged with the component's default classes using `twMerge`.

The outer row always includes `px-4` and a height class from `variant` (`h-10` or `h-12`); your classes are merged with that base. Override horizontal padding with `className` when needed (for example `px-0` or `pl-4 pr-1`).
