# SectionDivider

SectionDivider separates stacked sections with a horizontal line. Use it between groups of content in a column. For a border around a container, set `borderWidth` on [Box](../Box/Box.tsx) instead. It is not a vertical divider.

It renders an `<hr />`, stretches to the width of its container, draws a muted 1px line, and adds space above and below.

```tsx
import { SectionDivider } from '@metamask/design-system-react';

<SectionDivider />;
```

<Canvas of={SectionDividerStories.Default} />

## Props

`SectionDividerProps` matches [Box](../Box/Box.types.ts), except `asChild` and `children`. The divider always renders an `<hr />`. Override the line with `borderWidth`, `borderColor`, and `marginVertical`, or with `className` / `style`.

### Defaults

| Concern               | Default                      |
| --------------------- | ---------------------------- |
| Width                 | Full width of the container  |
| Line thickness        | `borderWidth={1}` (1px)      |
| Line color            | `BoxBorderColor.BorderMuted` |
| Space above and below | `marginVertical={5}` (20px)  |

```tsx
import {
  Box,
  BoxFlexDirection,
  SectionDivider,
  Text,
  TextVariant,
} from '@metamask/design-system-react';

export const SectionsExample = () => (
  <Box flexDirection={BoxFlexDirection.Column} gap={2}>
    <Text variant={TextVariant.BodyMd}>Section A</Text>
    <SectionDivider />
    <Text variant={TextVariant.BodyMd}>Section B</Text>
  </Box>
);
```

### `borderWidth`

Thickness of the line. `0` hides it. This sets the divider line only. It does not add a border on every side the way `Box` does.

Available values: `0`, `1`, `2`, `4`, `8`.

### `className`

Use the `className` prop to add Tailwind CSS classes to the component. These classes will be merged with the component's default classes using `twMerge`, allowing you to:

- Add new styles that don't exist in the default component
- Override the component's default styles when needed

### `style`

Use the `style` prop for dynamic inline styles that cannot be achieved with `className` alone. Prefer `className` with Tailwind classes for static styles.
