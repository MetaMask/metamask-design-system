# ModalFooter

`ModalFooter` is the bottom section of a modal. It hosts up to three action buttons — primary, secondary, and tertiary — and an optional slot above them for inline form controls (a "do not show again" checkbox, a disclaimer, etc.). The tertiary button always sits at the bottom.

The component owns the button semantics: it renders the primary button with `ButtonVariant.Primary`, the secondary button with `ButtonVariant.Secondary`, and the tertiary button with `ButtonVariant.Tertiary` automatically. Consumers configure each via `primaryButtonProps` / `secondaryButtonProps` / `tertiaryButtonProps`, but cannot override the variant. This mirrors the React Native `BottomSheetFooter` so the modal/sheet families share semantics across platforms.

```tsx
import { ModalFooter } from '@metamask/design-system-react';

<ModalFooter
  primaryButtonProps={{ children: t('confirm'), onClick: handleSubmit }}
  secondaryButtonProps={{ children: t('cancel'), onClick: handleClose }}
/>;
```

## Props

### `primaryButtonProps`

Props for the primary action button. Renders with `ButtonVariant.Primary` automatically. Appears after the secondary button (right in horizontal layout, below it in vertical layout) and above the tertiary button when one is set.

Pass the localized label as `children` and wire the click handler via `onClick`. `ModalFooter` is i18n-agnostic — pass localized strings from your application's i18n layer (e.g. `t('confirm')`).

### `tertiaryButtonProps`

Props for the tertiary action button. Renders with `ButtonVariant.Tertiary` automatically. Always appears last, at the bottom of the footer. In horizontal layout it sits on its own full-width row beneath the primary and secondary buttons. In vertical layout it is the last stacked button.

### `buttonsAlignment`

Layout direction for the action button row.

- `ButtonsAlignment.Horizontal` (default) — primary and secondary share the row, each takes `flex-1`. Order: secondary, primary. A tertiary button stays on its own full-width row at the bottom.
- `ButtonsAlignment.Vertical` — buttons stack with full width. Order: secondary, primary, then tertiary at the bottom.

### `className`

Use the `className` prop to add custom CSS classes to the outer `<footer>` element. These classes are merged with the component's defaults via `twMerge`, so consumer utilities override the defaults (for example, `className="px-0"` wins over the internal `px-4`).
