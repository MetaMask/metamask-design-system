# ListItem

ListItem is a padded list row for settings, asset lists, and menus. It wraps [Content](../Content/README.mdx) in a `Box` shell (`px-4 py-3`) and owns row shell accessories (`startAccessory`, `endAccessory`). For the inner row layout without padding, click handling, or shell accessories, use [Content](../Content/README.mdx) directly.

The row root is transparent by default so it inherits the surface behind it. Place list items inside a parent that sets the list background (for example a `Box` or page section). Interactive rows apply a semi-transparent `active:bg-pressed` tint while pressed, which reads correctly over different parent backgrounds without per-row color setup.

```tsx
import {
  Box,
  BoxBackgroundColor,
  ListItem,
} from '@metamask/design-system-react';

<Box backgroundColor={BoxBackgroundColor.BackgroundDefault}>
  <ListItem
    isInteractive
    title="Network"
    description="Ethereum Mainnet"
    value="1.234 ETH"
    onClick={() => {}}
  />
</Box>;
```

## Background and pressed feedback

ListItem does not apply a default row background. Define the list surface on the parent container and keep rows transparent so press feedback stays consistent across the list.

When `isInteractive` is `true`, the row applies `active:bg-pressed` while pressed—a general-purpose tint meant to layer over the parent background. In most layouts you do not need to set row background or pressed colors yourself.

Reserve row-level backgrounds for designs that require them (for example a highlighted, warning, or disabled row). If you set a custom idle background on a row, also define how that row should look when pressed so feedback remains visible—for example with `active:` variants in `className`.

```tsx
import {
  Box,
  BoxBackgroundColor,
  ListItem,
} from '@metamask/design-system-react';

// Typical: parent owns the surface
<Box backgroundColor={BoxBackgroundColor.BackgroundDefault}>
  <ListItem isInteractive title="Settings" onClick={() => {}} />
  <ListItem isInteractive title="Security" onClick={() => {}} />
</Box>;

// Row-specific background (only when the design requires it)
<ListItem
  isInteractive
  title="Action required"
  onClick={() => {}}
  className="bg-warning-muted active:bg-warning-muted-pressed"
/>;
```

## Props

### `isInteractive`

When `true`, the root is focusable with `role="button"`, accepts `onClick`, and applies pressed styles. When `false` (default), the root is a static `Box`.

Interactive rows stay transparent at rest and apply `active:bg-pressed` while pressed. See [Background and pressed feedback](#background-and-pressed-feedback) for how this interacts with parent surfaces and custom row backgrounds.

### `variant`

Layout variant controlling row min-height, vertical alignment, and which secondary slots render.

Available values:

- `ListItemVariant.OneLine` — 48px min height (incl. padding), centered; omits `description` and `subvalue`
- `ListItemVariant.TwoLines` — 72px min height, centered; all slots
- `ListItemVariant.MultiLine` — 88px min height, top-aligned; all slots

### `titleProps`, `descriptionProps`, `valueProps`, `subvalueProps`

Props merged onto text when the matching field is a string. Overrides default text styles. For `descriptionProps`, `valueProps`, and `subvalueProps`, pass `isHidden` / `length` to mask string content via `SensitiveText`.

See [Content/README.mdx](../Content/README.mdx) for types and examples.

### `titleStartAccessory`, `titleEndAccessory`, `descriptionStartAccessory`, `descriptionEndAccessory`, `valueStartAccessory`, `valueEndAccessory`, `subvalueStartAccessory`, `subvalueEndAccessory`

Optional inline accessories on the same line as the matching text field.

See [Content/README.mdx](../Content/README.mdx) for types and examples.

### `className`

Use the `className` prop to add Tailwind CSS classes to the component. These classes will be merged with the component's default classes using `twMerge`, allowing you to:

- Add new styles that don't exist in the default component
- Override the component's default styles when needed

Applied on the root `Box`, merged with default padding (`px-4 py-3`). Prefer layout overrides (padding, radius, borders) over row backgrounds. If you set a row background, pair it with an appropriate pressed treatment—see [Background and pressed feedback](#background-and-pressed-feedback).
